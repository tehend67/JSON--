# 🔄 JSON Converter

**JSON Converter** — это мощное, модульное и стильное десктопное приложение на Python с графическим интерфейсом. Оно предназначено для умного конвертирования файлов `.json` в удобные табличные форматы.

---

## ✨ Ключевые возможности

* **Умная конвертация:** Автоматически распаковывает вложенные списки и словари JSON в ровные таблицы (благодаря функции `pd.json_normalize`).
* **Поддерживаемые форматы:**
  * 📊 **CSV** (Comma-Separated Values)
  * 📗 **Excel** (XLSX)
  * ⚙️ **YAML** (Идеально для конфигураций)
  * 📝 **XML** (Структурированные данные)
  * 🌐 **HTML** (Готовые веб-таблицы)
  * 📖 **Markdown** (Таблицы для README и документации)
* **Потрясающий визуал:**
  * 🎨 Поддержка Светлой и Тёмной темы.
  * 🔘 Кастомные переключатели в стиле iOS/Android.
  * ℹ️ Удобные одноразовые всплывающие подсказки (Tooltips).
  * 🕒 Виджеты реального времени (Дата и Часы).
  * 🌟 **Анимированный фон:** Летающие на заднем плане названия форматов, создающие эффект глубины.
* **Модульная архитектура:** Код разделён на 6 компактных файлов для лёгкой поддержки и масштабируемости.

---

## 📂 Структура проекта

* `json_converter.py` — Главный файл-запускатор (точка входа).
* `ui_main.py` — Сборка основного графического интерфейса.
* `animations.py` — Фоновые анимации, тултипы и кастомные переключатели.
* `settings_ui.py` — Выезжающая панель настроек.
* `converter_core.py` — Ядро конвертации (работа с данными через Pandas).
* `formats_config.py` — Списки форматов, расширений и палитры тем.
* `run.bat` — Скрипт для быстрого запуска в один клик.
* `requirements.txt` — Список необходимых Python-библиотек.

---

## 📦 Используемые библиотеки (Зависимости)

Проект использует мощные современные инструменты для работы с данными. Все они уже прописаны в `requirements.txt`:
* **`pandas`** — Сердце программы. Выполняет всю тяжёлую работу по "плоской нормализации" (`json_normalize`), превращая любые вложенные списки и словари JSON в идеальную ровную таблицу.
* **`openpyxl`** — Требуется `pandas` "под капотом" для правильного сохранения таблиц в формате Microsoft Excel (`.xlsx`).
* **`pyyaml`** — Отвечает за аккуратное и безошибочное сохранение данных в формат конфигураций YAML.
* **`tabulate`** — Используется для красивой текстовой отрисовки таблиц при экспорте в формат Markdown.

*(Примечание: графический интерфейс `tkinter`, а также модули `json` и `os` встроены в стандартную библиотеку Python 3.12 и скачивания не требуют).*

## 🚀 Установка и Запуск

Приложение написано на **Python 3.12**. Убедитесь, что Python установлен на вашем компьютере.

### Вариант 1: Быстрый запуск (Для Windows)
Просто дважды кликните по файлу **`run.bat`**. 
Скрипт автоматически установит все нужные библиотеки и запустит графический интерфейс.

### Вариант 2: Запуск через консоль
Если вы хотите запустить проект вручную:
1. Откройте терминал в папке с проектом.
2. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```
3. Запустите программу:
   ```bash
   python json_converter.py
   ```

---

## 🛠 Как пользоваться
1. Запустите программу.
2. Нажмите центральную кнопку **«Выбрать JSON файл»**.
3. В появившемся выпадающем списке выберите нужный вам формат (CSV, Excel и т.д.).
4. Нажмите **«Конвертировать»** и выберите место для сохранения готового файла.
5. (Опционально) Нажмите на шестерёнку в правом верхнем углу, чтобы сменить тему или включить виджеты времени!
